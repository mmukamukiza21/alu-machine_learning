# Linear Algebra

This project covers fundamental linear algebra concepts and their implementation using Python and NumPy, including:

- Vectors and matrices
- Matrix slicing and shape
- Transpose operations
- Element-wise operations (addition, subtraction, multiplication, division)
- Matrix concatenation
- Matrix multiplication
- Broadcasting with NumPy

## Requirements

- Python 3.5
- NumPy 1.15
- pycodestyle 2.5

All scripts are executable and follow pycodestyle conventions.
